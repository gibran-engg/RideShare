# Ride-Sharing Platform

A Node.js-based ride-sharing platform inspired by systems such as Ola and Uber.

## Actors

- Rider
- Driver
- Admin

## External Systems

- Map API
- SMS / Messaging Service

## Architecture

The current system architecture is documented in the `architecture/` directory.

## System Goal

The Ride-Sharing Platform allows riders to request trips,
drivers to accept and complete trips, and administrators
to monitor and manage the overall platform.

## Initial Scope

The platform will support:

1. Rider registration and authentication
2. Driver registration and onboarding
3. Driver document and vehicle verification
4. Ride booking
5. Driver ride acceptance
6. Ride lifecycle management
7. Location and map integration
8. Payments
9. Notifications
10. Administrative monitoring
